# Round-6 Candidate Register — Seismic Proximity, Topographic Curvature, Conductivity Fabric, Magnetic Texture, Grav-Mag Decorrelation

> **Status:** preregistered on 2026-09-28 **before** implementing Round-6 feature code and before running the Round-6 gate. The emission policy is frozen from Round-5: greedy non-maximum suppression Chebyshev radius 2 (5×5), budget 2 % of valid footprint, deterministic tie-break. No DrivenData slot is spent in this session under any outcome. A hypothesis is not a discovery. `PASS` on a source check means only that the source can be manually reviewed.

## 0. Why this round exists

1. **Round-5 closed the emission-geometry gap.** With identical multi25 probabilities, top-k @ 2 % → NMS-3 @ 2 % moved mean DTI from 0.09071 → 0.22138 (dense), 0.04489 → 0.11178 (sparse), 0.06759 → 0.19380 (off-catalogue, 4/4 folds). The 2.5–2.9× gain dwarfs all feature gains from rounds 1–4.
2. **With emission fixed, rounds 1–5 geological arms cluster within ±0.0008 (dense) / ±0.0018 (sparse).** No arm beat multi25+NMS on ≥3/4 folds on both truth protocols. That is the actionable finding: the decision layer, not the feature list, was the bottleneck. Round-6 therefore tests only mechanism-distinct channels that were never built before, using the frozen NMS emission.
3. **Band `deq_n100a15` (B10) has never been used.** Identity checks in Round-5 verified its range (0 … 4.96e6, median 622.8 inside footprint, 15,759 zero pixels). It is the only supplied band with zero usage in all prior registers.
4. **External 1 m DEM and Sentinel-2 remain viable but transport-blocked.** Their sources are re-verified below as free/official and obtainable via the GitHub-runner bridge pattern.

## 1. Metric geometry reminder (frozen)

Official metric ([problem description, Performance metric](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/)): distance-weighted Tversky index, α=0.2, β=0.8, R=300 m = 3 px triangular kernel. TP is per-truth-pixel `max` over 5×5, so NMS radius 2 is the sparsest emission that can credit every truth pixel. Budget 2 % selected on folds 0–1 sparse protocol in Round-5 and frozen.

## 3. Preregistered decision rule (fixed before any Round-6 arm is scored)

1. **Emission policy for every Round-6 arm:** NMS radius 2 (5×5), descending probability, deterministic tie-break by pixel index, budget 2 % (same as Round-5).
2. **Gate (must pass all):**
   a. on the frozen masked spatial holdout (512-px blocks, 12-px collar, seed 12027, official pixel-exact catalogue mask on FP, leakage probe 0.0000), mean DTI over 4 folds with NMS-3 @ 2 %: new arm > multi25 reference on ≥3/4 folds on **both** truth protocols (dense catalogue truth and sparse 20 % truth, seed 4242+f);
   b. no leakage (probe 0.0000 every fold);
   c. mechanism-distinct: max |corr| vs all round-1..5 channels <0.50.
3. **A pass authorises packaging a GeoTIFF for the site. It does not authorise release.** The standing strongest-sibling-baseline requirement (`evidence/preregistered-hypotheses.md`) is still unsatisfied. No weekly submission slot is spent in this session under any outcome.
4. **External arms H30/H31:** source must be verified free/open and obtainable before proposing as viable. They are, but transport is blocked, so they are not scored here.
